## The label

83 characters — one line, straight-faced, with the punch landing in the last few words.

## How it works

`main.ts` (Node 22+) writes exactly that one line to `/output/entry.txt`:

```sh
node main.ts
```

It validates the label first: a single non-blank line of at most 120 characters, mirroring the competition gate.
